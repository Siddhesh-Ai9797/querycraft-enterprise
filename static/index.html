How it works

      
Every part runs in production. The code, tests and benchmarks are on GitHub.

      

        
Fine tuning
Phi-3 Mini 3.8B trained with QLoRA on 76,577 question and SQL pairs. Only 0.23% of the weights were trained, on one 8 GB GPU.

        
Serving
The merged model runs on vLLM on a Modal L4 GPU that sleeps when idle, so it only costs money while answering.

        
Finding tables
Table layouts are stored as embeddings in ChromaDB, so only the three most relevant reach the model.

        
Safety
Three checks before anything runs: SELECT only, a blocklist of risky words, and a dry run with PostgreSQL EXPLAIN.

        
Retries
If a query fails the checks, the error goes back to the model for one more try.

        
Tracking
Every question is logged to MLflow with timings, tokens and a quality score.
